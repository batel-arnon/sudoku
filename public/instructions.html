Instructions to play sudoka:

this game is quite similar to sudoku game, you need to have each number once in a cube, row and column.

also, there is an extra rule, that every number should place once in each relative place in the cube. now you can try playing.

for example, if i have 4 in the left up corner, i cant put 4 in any left up corner of the other cubes

enjoy!
